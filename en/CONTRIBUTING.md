# Contributing Guide

Thank you for your interest in this project! We welcome contributions of all kinds.

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion for improvement:

1. Search the existing [Issues](https://github.com/wangzi5151/chinese-use-github-helper/issues)
2. If you don't find one, create a new Issue
3. Describe the problem with a clear title
4. Provide detailed steps to reproduce it

### Submitting Content

#### Documentation Improvements

1. Fork this repository
2. Create your branch: `git checkout -b improvement/your-improvement`
3. Make your changes to the documentation
4. Commit your changes: `git commit -m "docs: improve XXX documentation"`
5. Push to your fork: `git push origin improvement/your-improvement`
6. Create a Pull Request

#### Adding New Content

1. Fork this repository
2. Create your branch: `git checkout -b feature/new-content`
3. Add the new documentation
4. Update README.md (if necessary)
5. Commit your changes: `git commit -m "feat: add XXX tutorial"`
6. Push to your fork: `git push origin feature/new-content`
7. Create a Pull Request

## Content Guidelines

### Documentation Structure

- Use a clear heading hierarchy
- Include a table of contents
- Provide example code
- Include links to relevant resources

### Code Examples

- Make sure the code runs
- Add explanatory comments
- Use a consistent code style

### Markdown Formatting

- Use standard Markdown syntax
- Keep the formatting consistent
- Use code blocks correctly

## Commit Message Guidelines

Follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:

```
<type>(<scope>): <subject>

<body>

<footer>
```

### Types

| Type | Description |
|------|-------------|
| `feat` | A new feature |
| `fix` | A bug fix |
| `docs` | Documentation updates |
| `style` | Formatting changes |
| `refactor` | Refactoring |
| `test` | Tests |
| `chore` | Build/tooling |

### Example

```
docs: update README installation instructions

Added detailed steps for installing with npm.
Fixed a broken link.

Closes #42
```

## Code of Conduct

### Our Pledge

In order to create an open and friendly environment, we pledge to:

- Respect everyone
- Accept constructive criticism
- Focus on what is best for the community
- Show empathy toward other community members

### Unacceptable Behavior

- The use of sexualized language or imagery
- Trolling, insulting/derogatory comments, or personal attacks
- Public or private harassment
- Publishing others' private information
- Other unprofessional or unethical conduct
