# GitHub Keyboard Shortcuts Guide

## Global Shortcuts

| Shortcut | Function |
|----------|----------|
| `.` | Press `.` in repository to open Web editor |
| `T` | File search |
| `S` or `/` | Search |
| `G` then `N` | Jump to notifications |
| `G` then `C` | Jump to code |
| `?` | Show shortcut help |

## Repository Page

| Shortcut | Function |
|----------|----------|
| `G` then `R` | Jump to repository |
| `G` then `A` | Jump to Actions |
| `G` then `I` | Jump to Issues |
| `G` then `P` | Jump to Pull Requests |
| `G` then `B` | Jump to project board |
| `G` then `W` | Jump to Wiki |

## File Operations

| Shortcut | Function |
|----------|----------|
| `E` | Edit file |
| `.` | Open in Web editor |

## Pull Request

| Shortcut | Function |
|----------|----------|
| `C` | Create new comment |
| `Ctrl+Enter` or `Cmd+Enter` | Submit comment |
| `E` | Edit title/description |

## Issue

| Shortcut | Function |
|----------|----------|
| `C` | Create new comment |
| `Ctrl+Enter` or `Cmd+Enter` | Submit comment |
| `L` then select label | Add label |
| `A` then select person | Add assignee |

## Code Review

| Shortcut | Function |
|----------|----------|
| `Ctrl+Enter` or `Cmd+Enter` | Submit review |
| `Shift+Enter` | Add new line (don't submit) |

## Editor

| Shortcut | Function |
|----------|----------|
| `Ctrl+/` or `Cmd+/` | Comment/uncomment |
| `Ctrl+Z` or `Cmd+Z` | Undo |
| `Ctrl+Shift+Z` or `Cmd+Shift+Z` | Redo |
| `Tab` | Indent |
| `Shift+Tab` | Unindent |

## Discussions

| Shortcut | Function |
|----------|----------|
| `C` | Create new comment |
| `Ctrl+Enter` or `Cmd+Enter` | Submit comment |
| `+1` | Like |
| `heart` | Favorite |

## General Navigation

| Shortcut | Function |
|----------|----------|
| `G` then `H` | Jump to homepage |
| `G` then `E` | Jump to explore |
| `G` then `S` | Jump to settings |
| `G` then `U` | Jump to profile |
| `Esc` | Close dialog/deselect |

## Mobile Shortcuts

GitHub Mobile app supports:
- Swipe left/right to switch tabs
- Pull down to refresh
- Long press for quick actions

## Tips

1. **Press `.` to open Web editor**: This is the most commonly used shortcut, can edit code directly in browser
2. **Press `?` for help**: Press `?` on any page to see all shortcuts for that page
3. **`G` + `letter`**: This is quick navigation combo, can quickly jump to different pages

## Custom Shortcuts

Although GitHub itself doesn't support custom shortcuts, you can use browser extensions:

- **Refined GitHub**: Enhance GitHub features
- **GitHub Keyboard Shortcuts**: Add more shortcuts
